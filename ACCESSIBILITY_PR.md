# Доступность текста документации REST API

Мы добавили в стайлгайд раздел о доступности текста и включили его в навигацию MkDocs.
Мы хотели собрать в одном месте правила, которые помогают делать документацию понятнее
и учитывать чтение с клавиатуры и экранным диктором.

В разделе описали понятные формулировки, порядок заголовков, названия ссылок, alt-текст,
использование цвета, оформление таблиц и кода. Отдельно добавили примеры сообщений об ошибках
и список действий для ручной проверки страницы. Правила получили номера X01–X07.

## Проверки

Мы запустили линтер Markdown, проверку JSON-примеров и строгую сборку MkDocs.
Все проверки прошли без ошибок. Экранным диктором сайт пока не проверяли,
поэтому полное соответствие WCAG не заявляем.
