# Доступность текста документации REST API

Добавил в стайлгайд раздел о доступности текста и включил его в навигацию MkDocs.
Хотел собрать в одном месте правила, которые помогают делать документацию понятнее
и учитывать чтение с клавиатуры и экранным диктором.

В разделе описал понятные формулировки, порядок заголовков, названия ссылок, alt-текст,
использование цвета, оформление таблиц и кода. Отдельно добавил примеры сообщений об ошибках
и список действий для ручной проверки страницы. Правила получили номера X01–X07.

## Проверки

Запустил линтер Markdown, проверку JSON-примеров и строгую сборку MkDocs.
Все проверки прошли без ошибок. Экранным диктором сайт пока не проверял,
поэтому полное соответствие WCAG не заявляю.
