# Первый запрос к Task API

Создайте учебную задачу и получите её идентификатор. Документ относится к контракту Task API 1.0.0.
Интерфейс программирования приложений (API) использует JSON и базовый путь `/api/v1`.

## Предварительные условия

- Доступен сервер, реализующий [учебный контракт](../assets/openapi.yaml).
- Установлены Bash и curl. В Windows используйте Git Bash или WSL.
- Получен токен доступа с правом `tasks:write` у администратора вашего стенда.
- Известен HTTPS-адрес сервера. `https://api.example` - демонстрационный адрес, он не обслуживает запросы.

Репозиторий не содержит сервер и не выдаёт токены. Без отдельного стенда можно изучить примеры,
но выполнить HTTP-запрос к работающему Task API нельзя.

## Выполнение

1. В Bash задайте адрес своего стенда и введите токен без отображения на экране.

   ```bash
   export BASE_URL='https://api.example'
   read -r -s -p 'Токен доступа: ' TOKEN
   printf '\n'
   export TOKEN
   ```

   Замените значение `BASE_URL` адресом стенда. Не сохраняйте токен в файлах репозитория.

2. Создайте задачу. Заголовок `-i` в ответе curl позволяет увидеть HTTP-статус и `Location`.

   ```bash
   curl --include --fail-with-body \
     --request POST "${BASE_URL}/api/v1/tasks" \
     --header "Authorization: Bearer ${TOKEN}" \
     --header 'Content-Type: application/json' \
     --header 'Accept: application/json, application/problem+json' \
     --data '{"title":"Подготовить документацию"}'
   ```

3. Проверьте статус `201 Created` и `Location: /api/v1/tasks/42`.
   Число `42` показано для примера; сервер выдаёт фактический идентификатор.
   Тело ответа по контракту имеет такой вид:

   ```json
   {
     "id": 42,
     "title": "Подготовить документацию",
     "status": "OPEN"
   }
   ```

4. Удалите токен из переменных текущей оболочки после работы.

   ```bash
   unset TOKEN
   ```

## Ошибки

| Статус | Возможная причина | Действие |
| --- | --- | --- |
| `400` | Пустой `title` или некорректный JSON | Исправьте тело по справочнику |
| `401` | Нет токена или токен истёк | Получите действительный токен у администратора |
| `403` | Нет права `tasks:write` | Запросите нужное право |
| `415` | Неподдерживаемый `Content-Type` | Укажите `application/json` |

При обрыве соединения не повторяйте POST вслепую: первая задача могла быть создана.
Контракт не предоставляет идемпотентный ключ. Уточните результат на стенде перед повтором.
Поля, ограничения и формат ошибки описаны в [справочнике создания задачи](create-task.md).
