# Область применения

Руководство предназначено для авторов русскоязычной документации REST API на Java и Spring Boot.
Задача читателя - интегрировать клиент с API без догадок о формате запросов и ошибках.

## S01. Аудитория и версия

Обязательно укажите назначение документа и версию контракта. В инструкции перечислите предварительные условия.
Разделяйте версию API (`v1`) и версию руководства (`1.0.0`). Не обещайте совместимость без проверки.

## S02. Приоритет требований

Сначала применяйте опубликованный контракт API, затем этот стайлгайд, затем внешние рекомендации.
Если текст противоречит контракту, исправьте текст или согласуйте изменение контракта в том же PR.
Не выдавайте локальное соглашение о названиях за обязательное требование HTTP.

## S03. Уровни требований

«Обязательно» - условие принятия изменения. «Рекомендуется» - предпочтительный вариант.
Отступление от обязательного правила требует пояснения и решения рецензента в PR.
Пример: внутреннее имя поля сохраняют в коде, даже если оно отличается от термина в русском тексте.
