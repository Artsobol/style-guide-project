# Язык и терминология

## L01. Тон и действие

Обязательно используйте нейтральный деловой тон и конкретный глагол действия.
Обращайтесь к читателю на «вы» со строчной буквы. В шаге описывайте одно основное действие.
Не используйте оценочные слова «просто», «очевидно», «легко».

| Неудачно | По правилу |
| --- | --- |
| Просто дерните ручку | Выполните запрос `POST /api/v1/tasks` |
| Должна быть произведена авторизация | Передайте токен в заголовке `Authorization` |
| Система не работает | Сервер вернул `503`. Повторите запрос позже |

## L02. Словарь

Обязательно применяйте один термин к одной сущности. Идентификаторы в коде сохраняйте без перевода.

| Термин | Значение | Избегать |
| --- | --- | --- |
| Конечная точка API | Сочетание метода и пути | Ручка |
| Запрос | HTTP-сообщение клиента | Реквест |
| Ответ | HTTP-сообщение сервера | Респонс |
| Тело запроса | Данные после заголовков | Боди |
| Токен доступа | Учётные данные Bearer | Ключ, если контракт использует токен |
| Задача | Сущность `Task` | Таска |

## L03. Сокращения и заимствования

Обязательно раскройте предметное сокращение при первом употреблении: «интерфейс программирования приложений (API)».
Для аудитории разработчиков HTTP, JSON и URL допустимы без расшифровки.
Используйте «стайлгайд» последовательно. Не переводите `Spring Boot`, `Content-Type` и имена Java-классов.

## L04. Числа, даты и единицы

В тексте используйте «15 октября 2026 года», в JSON — формат контракта, например `2026-10-15T12:00:00Z`.
Явно указывайте часовой пояс и единицу измерения: `timeout` в миллисекундах.
Диапазоны записывайте однозначно: «от 1 до 120 символов включительно».
В примерах JSON используйте точку как десятичный разделитель.
