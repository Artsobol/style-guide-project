# Структура документов

## D01. Заголовок и вводный абзац

Обязательно используйте один заголовок первого уровня, который называет задачу или операцию.
Во вводном абзаце объясните назначение и ожидаемый результат. Затем укажите версию и условия.
Иерархия заголовков идёт без пропусков: H1, H2, H3.

## D02. Шаблон инструкции

Обязательный порядок: назначение, предварительные условия, нумерованные действия,
ожидаемый результат, устранение ошибок и ссылка на справочник.
Перед командой объясните её назначение, после команды покажите признак успеха.
Все дополнительные файлы и переменные должны быть определены до использования.

```markdown
# Первый запрос к API

Назначение и версия.

## Предварительные условия

Необходимые инструменты, адрес и права.

## Выполнение

1. Подготовьте переменные.
2. Выполните запрос.
3. Проверьте результат.

## Ошибки

Причина, признак и действие.
```

## D03. Шаблон справочника операции

Обязательный порядок: назначение, метод и путь, авторизация, параметры и тело,
пример запроса, успешный ответ, ошибки и связанные материалы.
Таблица поля содержит имя, тип, обязательность, допустимость `null`, ограничение и описание.
Для query-параметра укажите значение по умолчанию; для path-параметра - допустимый формат.
Если параметров нет, напишите это явно.

## D04. Разделение видов текста

В инструкции описывайте последовательность действий, в справочнике - полный контракт операции.
Общие сведения об авторизации храните в одном месте и связывайте ссылками.
При удалении страницы обновляйте навигацию и все входящие ссылки в том же PR.
